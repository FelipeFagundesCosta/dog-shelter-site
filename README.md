# Cão Quixote (`dog-shelter-site`)

Site do **Cão Quixote**, um sebo cuja renda é revertida para a causa animal: alimentação, tratamento e cuidados de animais de rua. Contexto completo em [`docs/contexto.md`](docs/contexto.md).

Projeto web gerenciado pelo pipeline WebDev (Analista → Implementador → Tester) com Spec Kit.

- Constituição: `.specify/memory/constitution.md`
- Regras para agentes: `AGENTS.md`
- Specs das features: `specs/NNN-nome-curto/`
- Portões de qualidade: `bash scripts/gates.sh . gates-out`

Rodar uma tarefa:

```bash
~/Documents/WebDev/.orquestracao/pipeline/run-tarefa.sh /home/felipe/Documents/WebDev/dog-shelter-site caminho/da/tarefa.md --bg
```
